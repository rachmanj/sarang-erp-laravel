# FAQ Sarang ERP

## Pertanyaan Umum

1. **Apa itu Sarang ERP?**
   Sarang ERP adalah aplikasi ERP (Enterprise Resource Planning) untuk perusahaan trading di Indonesia. Modul utamanya meliputi Penjualan (Sales Order → Delivery Order → Sales Invoice → Sales Receipt), Pembelian (Purchase Order → GRPO → Purchase Invoice → Purchase Payment), Akuntansi (jurnal, AR/AP, rekonsiliasi bank), Inventaris (metode FIFO), dan Aset Tetap beserta penyusutannya. Mendukung multi-entitas (beberapa perusahaan dalam satu instalasi).

2. **Bagaimana cara mengakses Sarang ERP?**
   Sarang ERP adalah aplikasi web. Akses melalui browser (Chrome, Edge, atau Firefox) menggunakan URL yang diberikan oleh administrator/vendor Anda (contoh: `https://sarang-erp.xyz`). Aplikasi diinstal di server milik perusahaan Anda (on-premise), bukan cloud publik.

3. **Apakah Sarang ERP bisa diakses dari perangkat mobile?**
   Ya, halaman web dapat dibuka lewat browser di ponsel atau tablet. Namun karena fungsionalitas ERP yang lengkap (tabel, laporan, entri data), pengalaman terbaik adalah menggunakan desktop atau laptop. Tidak tersedia aplikasi mobile native.

4. **Bagaimana cara melakukan backup data?**
   Backup database dilakukan otomatis di sisi server (daily backup terjadwal oleh vendor). Pengguna tidak perlu melakukan backup dari dalam aplikasi. Untuk kebutuhan pemulihan atau salinan data, hubungi tim dukungan/vendor Anda.

5. **Siapa yang bisa membantu jika mengalami kendala?**
   Hubungi tim dukungan Sarang ERP — yaitu vendor/administrator yang mengelola instalasi Sarang ERP perusahaan Anda.

6. **Bagaimana cara mendapatkan akun/login?**
   Akun dibuat oleh administrator. Setiap pengguna memiliki peran (role) dengan hak akses (permission) tertentu sesuai tanggung jawabnya. Hubungi administrator Anda jika memerlukan akun baru atau perubahan hak akses.
